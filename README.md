# AI Literacy & Responsible Use Explorer

An interactive dashboard for exploring student generative AI usage, AI literacy self-assessments, information verification habits, and privacy awareness.

## Project Overview

Generative AI is increasingly used for learning, writing, assignments, and academic research. Understanding how students use these tools—and how they approach verification and responsible use—is an important area of educational research.

This project demonstrates how Python-based data analytics can help organize and visualize survey responses related to AI literacy and responsible AI practices.

## Key Features

- Interactive filters for study level and AI usage frequency
- Summary metrics and percentage calculations
- AI usage pattern visualizations
- Verification habit analysis
- Self-rated AI literacy comparisons
- Privacy awareness summaries
- Downloadable CSV data
- Research questions for further exploration

## Technology Stack

- Python
- Streamlit
- Pandas
- GitHub

## Getting Started

Install the dependencies:

`pip install -r requirements.txt`

Run the application:

`streamlit run app.py`

## Data and Research Integrity

The included records are entirely synthetic and intended only to demonstrate application functionality. They do not represent actual students, a university sample, or empirical research findings.

The dashboard provides descriptive summaries and does not establish causation. Self-reported awareness should not be interpreted as a validated measure of AI literacy.
